# 💰 Expense Tracker

A professional and feature-rich personal Expense Tracker web application built using HTML, CSS, and JavaScript.

The application helps users manage their income and expenses, set monthly budgets, analyze spending patterns, visualize financial data, and securely backup or restore their data using browser Local Storage.

## ✨ Features

- ➕ Add income and expense transactions
- ✏️ Edit existing transactions
- 🗑️ Delete transactions
- 🔍 Search transactions
- 🏷️ Filter by category
- 💰 Track income, expenses, and balance
- 📅 Filter transactions by month
- 📊 Monthly expense reports
- 💵 Monthly budget management
- ⚠️ Budget exceeded warning
- 📈 Spending analytics
- 🥧 Expense category chart
- 📊 Income vs Expense chart
- 📉 Monthly expense trend chart
- 🌙 Dark mode
- 💾 JSON backup and restore
- 📄 CSV export
- 🔔 Toast notifications
- 📱 Responsive design
- 💻 Data stored using browser Local Storage

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Chart.js
- Browser Local Storage

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

You can also use the Live Server extension in Visual Studio Code for development.

## 📊 Analytics

The dashboard provides useful insights such as:

- Total income
- Total expenses
- Current balance
- Average expenses
- Highest spending category
- Largest single expense
- Monthly expense comparison
- Budget usage
- Category-wise spending

## 💾 Data Management

The application stores transaction and budget information in the browser's Local Storage.

Users can:

- Download a complete JSON backup
- Restore a previous backup
- Export transactions as CSV
- Delete all transactions
- Reset the entire application

## 🎯 Project Goal

The goal of this project is to create a simple yet professional financial management application that helps users manage their income, track expenses, set monthly budgets, and understand their spending patterns through analytics and visualizations.
